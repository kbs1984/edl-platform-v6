# Engagement Metrics for Educational Identity

**Session**: 00020  
**Date**: 2025-08-17  
**Purpose**: How to measure student identity building success

---

## Core Identity Metrics (The Big 5)

### 1. Daily Active Identity (DAI)
- **Measurement**: Unique users with 3+ actions per day
- **Target**: 60% of registered users
- **Current**: 0% (no tracking implemented)

### 2. Identity Investment Score (IIS)
- **Formula**: Profile completion + Customizations + Achievements + Team membership
- **Target**: Average score > 35
- **Current**: 0 (no features implemented)

### 3. Social Identity Connections (SIC)
- **Measurement**: Team members + Profile interactions + Supervisor links
- **Target**: Average 5+ connections
- **Current**: 0 (no social features)

### 4. Identity Expression Rate (IER)
- **Measurement**: Weekly achievements + Customizations + Status updates
- **Target**: 3+ expressions per week
- **Current**: 0 (no expression tools)

### 5. Identity Persistence Score (IPS)
- **Measurement**: % active after 30 days
- **Target**: 70% retention
- **Current**: N/A (no users)

## North Star Metric

**Identity Obsession Score (IOS)**
```
IOS = (DAI × 0.3) + (IIS × 0.2) + (SIC × 0.2) + (IER × 0.2) + (IPS × 0.1)
```
